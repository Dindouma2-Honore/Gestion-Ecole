## Consommateur retenu

**Fichier** : `app/Modules/Socle/Services/DocumentService::peutAccéder()` — contrôle d'accès à la consultation de documents  
**Feature** : `socle.consulter`  
**Action** : `PRINT` (via `canPrint()`)  
**Contrôle avant** : `ModuleAccess::canAccessComponent()` ou `$user->hasAnyRole(['Fondateur', 'Directeur', 'Admin', 'Administrateur'])`  
**Contrôle après** : `AuthenticatedAuthorizationContract->canPrint('socle.consulter')`

## Architecture de décision

Flux exact :

1. Requête utilisateur → écran/contrôleur
2. `AuthenticatedAuthorizationService::canPrint('socle.consulter')` (bridge, injecte l'ID user authentifié)
3. `AuthorizationService::canRead(int $userId, string $featureCode)` — moteur strict, lit `authorization_grants`
4. Si grant existant → décision V1 (ALLOW/DENY)
5. Si aucun grant → DENY (pas de fallback legacy)
6. Fondateur → couche `TransitionalSuperAdminAuthorizationService` (bypass centralisé, rôles `[Fondateur, Admin, Administrateur, Super Admin]` uniquement)

## Gestion Fondateur

- **Mécanisme retenu** : `TransitionalSuperAdminAuthorizationService` — couche de compatibilité AU-DESSUS d'`AuthenticatedAuthorizationContract`
- **Emplacement** : `app/Modules/Socle/Services/TransitionalSuperAdminAuthorizationService.php`
- **Rôles concernés** : `Fondateur`, `Admin`, `Administrateur`, `Super Admin` — déjà reconnus par l'application existante (aucun rôle inventé)
- **Pourquoi le moteur V1 reste indépendant** : Le bypass est centralisé dans ce service transitionnel, pas dans `AuthorizationService` ni dans les consommateurs. Le moteur V1 évalue strictement les grants; le bypass n'est qu'une passerolle temporaire au-dessus.

## Absence de fallback legacy

Démontré : le consommateur migrated (`socle.consulter` via `canPrint()`) ne consulte plus jamais `legacy` + V1 simultanément pour la même décision. La source de vérité unique est maintenant :
- Soit un grant V1 dans `authorization_grants`
- Soit le bypass centralisé `TransitionalSuperAdminAuthorizationService` pour les super-admin reconnus
- Soit DENY par défaut (pas de "V1 autorise OU legacy autorise")
