# Pédagogie P0.1 — Inventaire technique

## 1. Inspecter (Vue d'ensemble)

Le module **Pédagogie** organise et exécute l'enseignement au sein de l'établissement (offre annuelle, affectations, programmes, emplois du temps, séances, appels, évaluations, notes, résultats, bulletins et décisions pédagogiques).

- **Models** : 27 models
- **Services / Actions** : 29 services
- **Jobs** : 3 jobs (dont `AnalyseProgramme`)
- **Contracts / DTO** : 14 contrats / interfaces
- **Events** : 1 event (`ReportCardPublished`)
- **Enums** : 4 enums
- **Filament Resources** : 18 resources (plus 1 support)
- **Filament Pages** : 11 pages
- **Tests existants** : 25 fichiers de test
